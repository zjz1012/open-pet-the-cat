# Open Pet the Cat 🐱

一个**纯前端、零后端、100% 开源**的 2.5D WebGL2 真实撸猫模拟器（v2.0）。代码、GLSL 着色器、Web Audio 音频合成与贴图资产全部从零独立构建。

> 无需游戏引擎、无需大型贴图包、无需外部音频文件——核心 JS 打包仅 **~28 KB gzip**，在桌面端与移动端浏览器均可流畅 60fps 运行。

---

## v2.0 全部核心玩法与特色

### 1. 真实 2.5D 体积毛发与触感物理（WebGL2 / GLSL ES 3.00）
- **20 层体积毛发 Shell 着色器**：发根采样花纹实现自然绒毛边界，支持发根自阴影（AO）、顺/逆毛各向异性光泽、猫背弧面窗光投影，以及斯芬克斯猫专属哑光绒面皮肤与自然皮肤褶皱。
- **Ping-Pong FBO 物理场**：四指 + 掌心多触点弹簧下陷与指尖凹陷阴影，滑动抚摸实时拨动毛流并缓慢回弹。

### 2. 真实猫脾气与「拍猫屁股」软体果冻回弹
- **顺毛享受 vs. 逆毛炸毛**：顺着毛轻抚会越撸越沉醉，偶发轻柔满足的“喵呜~”；但若**用力逆毛猛搓或猛拽尾巴**，会触发猫背神经性抽搐（Skin Twitch）、警戒飞机耳、尾巴急甩，惹急了还会轻微“哈气”把你的手弹开！
- **拍猫屁股（Bongo Cat）**：短促轻点猫咪臀部或下背，触发软体果冻波纹回弹、沉闷 Q 弹的拍打音效与“屁股越拍翘越高”的连击反馈。

### 3. 特色道具切换（快捷键 `1` `2` `3` `4`）
- **徒手撸猫（`1`）**：写实掌心压陷、耳压变形、连拍屁股与猫脾气彩蛋。
- **木质排梳（`2`）**：胡桃木排梳会在猫背上留下**清晰的多道平行梳齿纹路**与丝滑光泽；梳长毛猫（布偶/西伯利亚/挪威森林等）还会不断在垫子边滚出**可推着玩的浮毛球**！
- **红点激光笔（`3`）**：垫子上投影微微颤动的红色激光点，猫咪的**头部与双耳会实时转向追踪红点**，尾巴进入猎手抖动模式，红点贴近猫头时还会蓄力向前轻扑。
- **涂鸦捏猫（`4`）**：直接在猫背上画斑块/爱心/美人痣，笔触在**发根层**实时参与 20 层毛发渲染，画出来直接变成真实的 3D 绒毛花纹！

### 4. 三态氛围与白噪音 ASMR（快捷键 `T`）
- **晴日暖阳** / **雨天午后**（窗玻璃流动雨滴光影投影 + Web Audio 细雨白噪音与猫呼噜声交融，可直接挂副屏当学习/助眠 ASMR 伴侣） / **月光时刻**。

### 5. 14 种猫咪品种 + 体型变形 + 拍立得拍照 & 专属链接分享
- 内置 14 种经典猫种（黑猫、橘猫、三花、白猫、银虎斑、奶牛、玳瑁、蓝猫、狸花、暹罗、布偶、西伯利亚、挪威森林、斯芬克斯），支持大小（65%–114%）与躯干胖瘦（80%–140%）实时变形。
- 一键导出 **拍立得风格合照 PNG**，或将定制品种、胖瘦、天气与自定义涂鸦压缩进 URL Hash，一键复制链接分享给朋友“云撸你家的猫”！

## 快速开始

```bash
npm install
npm run dev     # 本地预览 http://127.0.0.1:5173
npm run build   # 类型检查并构建纯静态产物至 dist/
```

## 项目结构

```text
├── index.html                 # 极简舞台、道具栏、涂鸦面板与控制栏
├── public/assets/
│   ├── cushion-bg.webp        # 原创窗边亚麻坐垫背景 (CC0)
│   └── petting-hand.webp      # 原创去背抚摸手部精灵 (CC0)
└── src/
    ├── main.ts                # 互动调度、连拍判定、道具与分享绑定
    ├── styles.css             # 晴日 / 雨天 / 月光三套自适应主题样式
    ├── breeds.ts              # 14 种猫咪花色与毛发参数表（欢迎 PR 新增！）
    ├── audio/
    │   └── purrEngine.ts      # 呼噜声 + 细雨 ASMR + 拍屁股 + 喵呜/哈气合成器
    ├── physics/
    │   └── catPhysics.ts      # 情绪/炸毛/抽搐、激光追踪、13 点平滑尾巴与浮毛球物理
    ├── paint/
    │   └── coatPainter.ts     # 3D 绒毛涂鸦画布、URL 压缩编解码与拍立得导出
    └── renderer/
        ├── shaders.ts         # Ping-Pong 物理场 + 20 层毛发/排梳/雨影/激光主着色器
        └── CatRenderer.ts     # WebGL2 渲染管线与动态纹理同步
```
