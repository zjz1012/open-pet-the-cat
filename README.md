# Open Pet the Cat 🐱

一个**纯前端、零后端、100% 开源**的 2.5D WebGL2 真实撸猫模拟器（灵感致敬 `pet-the-cat`，代码、着色器、音频与贴图资产全部从零独立构建）。

> 无需游戏引擎、无需大型贴图包、无需外部音频文件——核心 JS 打包后仅 **~22 KB gzip**，在桌面端与移动端浏览器均可流畅 60fps 运行。

---

## 核心特性

- **20 层体积毛发 Shell 着色器（WebGL2 / GLSL ES 3.00）**
  - 基于 2.5D 参数化猫体高度场与 LIC 各向异性毛流场，实现毛茸茸的自然边缘、发根至发梢体积自阴影（AO）、顺/逆毛各向异性光泽变化（Kajiya-Kay 风格），以及随猫背弧度起伏的窗光投影。
- **实时软体压陷与梳毛物理（Ping-Pong FBO）**
  - 四指 + 掌心多触点弹簧阻尼下陷形变与指尖凹陷阴影；滑动抚摸会按手势方向拨动毛流并缓慢回弹。
  - **独立部位物理反馈**：摸头时左右耳独立受压“飞机耳”回弹、摸下背时轻抬屁股、13 点 Catmull-Rom 平滑物理尾巴随抚摸与愉悦度自然卷曲摆动，辅以呼吸起伏动画。
- **14 种经典猫咪品种/花色（可扩展配置架构）**
  - 黑猫、橘猫、三花猫、白猫、银虎斑、奶牛猫、玳瑁猫、蓝猫、狸花猫、暹罗猫、布偶猫、西伯利亚猫、挪威森林猫（超长绒毛颈圈与蓬松大尾巴）、斯芬克斯无毛猫（哑光绒面皮肤与自然皮肤褶皱）。
- **程序化 Web Audio 呼噜声引擎**
  - 零外部音频文件：用 22–28 Hz 喉部脉冲调制 + 胸腔共振滤波 + 呼吸吸/呼双相气流噪声实时合成呼噜声，随抚摸节奏、区域与品种动态变化。
- **治愈系极简交互**
  - 日光 / 月光模式一键平滑切换（快捷键 `T`）
  - 整体大小（65%–114%）与躯干胖瘦（80%–140%）实时无级变形（头尾比例保持自然）
  - 键盘自动抚摸（`Space` / `Enter`）、全屏模式与触控屏适配

## 快速开始

```bash
# 安装依赖
npm install

# 本地开发预览（默认 http://127.0.0.1:5173）
npm run dev

# 类型检查并构建生产静态文件（输出至 dist/）
npm run build
```

构建产物位于 `dist/`，为纯静态站点，可直接部署到 **GitHub Pages**、**Cloudflare Pages**、**Vercel** 或嵌入展示页面（`vite.config.ts` 已配置 `base: './'` 支持任意子路径部署）。

## 项目架构

```text
├── index.html                 # 语义化极简舞台与控制栏 DOM
├── public/assets/
│   ├── cushion-bg.webp        # 原创窗边亚麻坐垫背景 (CC0)
│   └── petting-hand.webp      # 原创去背抚摸手部精灵 (CC0)
└── src/
    ├── main.ts                # 交互绑定、状态控制与 60fps 渲染循环
    ├── styles.css             # 温暖纸感日/夜双主题样式与响应式布局
    ├── breeds.ts              # 14 种猫咪花色与毛发物理参数表（欢迎 PR 新增！）
    ├── audio/
    │   └── purrEngine.ts      # Web Audio API 实时呼噜声合成引擎
    ├── physics/
    │   └── catPhysics.ts      # 呼吸、耳压、抬臀、13 点平滑尾巴与手部运动学
    └── renderer/
        ├── shaders.ts         # Ping-Pong 物理场着色器 + 20 层 2.5D 毛发主着色器
        └── CatRenderer.ts     # WebGL2 渲染管线与无缝多频噪声纹理生成器
```

## 欢迎贡献“你家的猫” 🎨

只需要在 [`src/breeds.ts`](./src/breeds.ts) 的 `CAT_BREEDS` 数组中新增一个配置对象（设置主/副毛色、毛长 `furLength`、蓬松度 `tailFluff` / `ruffFluff`、花纹模式 `pattern` 与呼噜基频 `purrHz`），即可加入新的猫咪品种或自定义花色，无需制作任何新贴图！
