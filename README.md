# Open Pet the Cat 🐱

一个**纯前端、零后端、100% 开源**的 2.5D WebGL2 真实撸猫模拟器，完整适配 **B站 Toy JS SDK**、**手机横屏沉浸模式**与**关注 UP 主解锁机制**。

> 无需游戏引擎、无需外部音频文件——核心 JS 打包仅 **~40 KB gzip**，桌面端、手机竖屏/横屏与 B站 App 内均可流畅 60fps 运行。

---

## 核心玩法与特色

### 1. 真实 2.5D 体积毛发、可爱猫脸与触感物理（WebGL2 / GLSL ES 3.00）
- **20 层体积毛发 Shell 着色器**：发根采样花纹实现自然绒毛边界，支持发根自阴影（AO）、顺/逆毛各向异性光泽、猫背弧面窗光投影，以及斯芬克斯猫专属哑光绒面皮肤与自然皮肤褶皱。
- **活灵活现的俯视猫脸**：平时温柔半眯/闭眼睡颜，被撸时惬意眯眼，追激光红点时睁开带眉骨阴影与眼神光的圆润大瞳孔萌眼，搭配精致哑光小鼻头与超细前向胡须。
- **Ping-Pong FBO 物理场（`512×320`）**：四指 + 掌心多触点弹簧下陷与指尖凹陷阴影，滑动抚摸实时拨动毛流并缓慢回弹。

### 2. 真实猫脾气、拍猫屁股 & 炸毛自舔毛
- **拍猫屁股（Bongo Cat）**：短促轻点猫咪臀部或下背，触发软体果冻波纹回弹、沉闷 Q 弹的拍打音效与“屁股越拍翘越高”的连击反馈。
- **逆梳炸毛 → 自己舔毛理顺**：用力逆毛猛搓或逆向梳毛会触发真实向外竖起的**细毛丝炸毛 + 瓶刷大尾巴**与猫背抽搐；停手约 1 秒后，小猫会自己侧头低肩节奏舔毛并伴随轻柔舔毛 ASMR 音效，一口一口把炸毛舔平！

### 3. 特色道具与三态氛围
- **徒手撸猫（`1`）**：写实掌心压陷、耳压变形、连拍屁股与猫脾气彩蛋。
- **木质排梳（`2`）**：顺着猫背垂直握持的胡桃木排梳，留下丝滑平行梳痕并在长毛猫身边滚出可推着玩的浮毛球。
- **红点激光笔（`3`）**：围着猫画圈，整只猫会带着柔性脊柱弯曲**原地 360° 转圈、在垫上小跑靠近并伸爪轻扑红点**！
- **参数化基因「捏猫工坊」（`C`）**：自由定制猫咪名字、8 种花纹基因 + 花纹分布种子、三层真实毛色、毛长/尾蓬松/围脖/光泽、呼噜声线（21–29 Hz）与猫脾气性格（天使粘人 / 傲娇主子 / 暴躁大佬），支持一键随机领养。
- **晴日 / 雨天午后 ASMR（窗外流动雨滴光影 + 细雨白噪音） / 月光时刻（`T`）**。

## B站 Toy JS SDK 集成与手机横屏适配

已在 [`index.html`](./index.html) 接入官方 `//s1.hdslb.com/bfs/seed/toy/app/sdk/toy-sdk.js`，核心封装在 [`src/sdk/toySdk.ts`](./src/sdk/toySdk.ts)：

| SDK 能力 | 本项目接入场景 |
| :--- | :--- |
| **`getAuthorRelation` + `getAuthorProfile` + `navigate`** | **关注 UP 主解锁锁机制**：基础撸猫与 10 种经典猫免费畅玩；**4 只稀有长毛/无毛猫（布偶/西伯利亚/挪威森林/斯芬克斯）、木质排梳、红点激光笔、基因捏猫工坊与雨天 ASMR** 需关注作者解锁，返回页面自动重验。 |
| **`getContainerState` + `onContainerChange` + `setContainerMode`** | **手机横屏沉浸 & 安全区适配**：自动读取 `safeArea` 避让状态栏、手势条与 B站 App 右上角胶囊；支持点击横屏按钮原子请求 `{ orientation: 'landscape', immersive: true }`，横屏下自动切换全屏紧凑底栏布局。 |
| **`saveImageToAlbum` / `share`** | 拍立得合照在 B站 App 内直接保存系统相册（压缩至 < 400 KB）；分享小猫调用原生 `toy.share({ path: 'index.html?cat=...' })`，Web 端优雅降级为下载与复制链接。 |
| **`checkInputSafety`** | 仅在用户主动分享/导出带自定义名字的拍立得时校验名字安全（不按击键触发，严格遵守配额与三态判定）。 |
| **`getCloudStorage` / `setCloudStorage` + `onPageClose`** | 单 key 批量云存档（页面隐藏或分享时落盘，支持 `307044` 指数退避）与页面关闭音频清理。 |

> 在非 B站独立浏览器预览（本地开发 / GitHub 预览）时，弹窗提供「本地预览模拟解锁」按钮方便自测；在真实 B站 Toy 环境内该按钮严格隐藏，全部以平台 `getAuthorRelation` 为准。

```bash
npm run build   # 类型检查并构建纯静态产物至 dist/（可直接上传 B站 Toy）
```
