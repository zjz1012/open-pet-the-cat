# 呼噜噜云撸猫（Open Pet the Cat）🐱

一个**纯前端、零后端、100% 开源**的 2.5D WebGL2 真实撸猫模拟器，支持**手机横屏沉浸模式**、**真实多版本猫呼噜 ASMR**、**拍立得取景框**与**猫咪配置存档**。

> 无需游戏引擎，核心打包体积轻量（含 3 套真实猫呼噜音轨与贴图总包 < 900 KB），桌面端、手机竖屏/横屏与 B站 App 内均可流畅 60fps 运行。

---

## 核心玩法与特色

### 1. 2.5D 真实体积毛发与自然俯视揣手造型（WebGL2 / GLSL ES 3.00）
- **20 层体积毛发 Shell 着色器**：发根采样花纹实现柔和绒毛边界，支持发根自阴影（AO）、顺/逆毛各向异性光泽与猫背弧面窗光投影。
- **自然低头揣手轮廓与耳毛一体过渡**：采用真实俯视熟睡揣手姿态，头颈柔和收窄衔接，耳根蓬松冠毛向耳尖连续过渡为细腻短绒，兼具立体耳脊与柔和耳压回弹，无割裂拼接感。
- **Ping-Pong FBO 触感物理场（`512×320`）**：四指 + 掌心多触点弹簧压陷与凹陷阴影，滑动抚摸实时拨动毛流并缓慢回弹。

### 2. 真实猫呼噜 ASMR（3 套实录声线 + 抚摸动态差异）
- **激活即默认开启声音**：页面首次交互自动唤醒音频，无需额外手动点开音量键。
- **抚摸与静置动态起伏**：不摸猫时呼噜声逐渐柔和淡出至轻柔底噪；手指顺毛轻抚时呼噜声温和抬升，清晰贴耳而不刺耳。
- **3 套真实猫呼噜版本 + 音量滑块**：内置「温润 / 低沉 / 轻柔」三套实录无缝循环呼噜音轨，支持「随品种自动匹配」或手动切换与 `5%–100%` 音量细调。

### 3. 真实猫咪尾巴逻辑、拍屁股 & 炸毛自舔毛
- **拍猫屁股（Bongo Cat）**：轻点猫咪臀部或下背，触发软体果冻波纹回弹、沉闷 Q 弹的拍打音效、“屁股越拍翘越高”，且**尾巴会瞬间开心绷直微颤**。
- **顺毛轻撸**：尾巴保持自然放松的轻微慢摆。
- **逆毛炸毛 → 剧烈甩尾 → 低头自舔理顺**：用力逆毛猛搓或逆梳会触发真实向外竖起的**细毛丝炸毛 + 瓶刷大尾巴**与猫背抽搐；停手后小猫会先**剧烈左右甩动尾巴几次**，消气后再低头侧肩节奏舔毛（附舔毛 ASMR 音效），把炸毛一口一口舔顺。
- **静置不碰**：平时安静蜷卧，每隔数秒随机出现一次慵懒慢摆或尾尖轻弹。

### 4. 13 种猫咪、互动道具、捏猫工坊与可爱拍立得
- **13 种精选猫种**：黑猫、橘猫、三花猫、白猫、银虎斑、奶牛猫、玳瑁猫、蓝猫、狸花猫、暹罗猫、布偶猫、西伯利亚猫、挪威森林猫。
- **徒手撸猫（`1`）**：写实掌心压陷、耳压变形、连拍屁股与真实猫脾气彩蛋。
- **木质排梳（`2`）**：顺着猫背垂直握持的胡桃木排梳，留下丝滑平行梳痕并在长毛猫身边滚出可推着玩的浮毛球。
- **红点激光笔（`3`）**：围着猫画圈，整只猫会带着柔性脊柱弯曲**原地 360° 转圈、小跑靠近并伸爪轻扑红点**。
- **参数化基因「捏猫工坊」（`C`）**：自由定制猫咪名字、7 种花纹基因 + 花纹分布种子、三层真实毛色、毛长/尾蓬松/围脖/光泽、呼噜声线（21–29 Hz）与猫脾气性格（天使粘人 / 傲娇主子 / 暴躁大佬），支持一键随机领养。
- **拍立得取景框 📸**：实时预览取景（三分线 + 十字对焦 + 四角取景标），内置 **奶油经典 / 樱花粉萌 / 复古胶片 / 手账贴纸** 4 款可爱相纸与自定义照片配文，拍摄带快门音效与闪光动画，支持手机相册/系统分享/浏览器直接保存。
- **晴日 / 雨天午后 ASMR（窗外流动雨滴光影 + 细雨白噪音） / 月光时刻（`T`）**。

## 快速开始

```bash
npm install
npm run dev     # 本地预览 http://127.0.0.1:5173
npm run build   # 类型检查并构建纯静态产物至 dist/
```
